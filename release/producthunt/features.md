# Features

- Upload Blender `.blend` and Octane `.orbx` packages.
- Choose still image or animation frame ranges where supported.
- See package pricing before sending.
- Track the package from upload to delivery.
- Download completed ZIP outputs.
- Keep a delivery receipt with SHA-256 proof.
- Use wallet balance without a subscription.
- Install the Blender add-on for Farpy Render Delivery.
- Compare real Benchmark pages without fake leaderboard numbers.

## Current Limits

- Best for small render packages today.
- Start with previews, tests, splash screens, and short frame ranges.
- Product Hunt screenshots do not include fake live render metrics.
