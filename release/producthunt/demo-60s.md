# 60 Second Demo Script

## 0-5 sec - Problem

"Rendering should not feel like a black box. Artists need to know what they sent, what it costs, and what they got back."

## 5-15 sec - Upload package

"On Farpy, start with a small Blender or Octane package. Choose still or animation frames and delivery speed."

## 15-35 sec - Render progress

"The workspace tracks the package journey. Farpy only shows honest states. If a real state is not available, it does not invent percentages."

## 35-50 sec - Receipt

"When a package is delivered, Farpy provides a delivery receipt with output proof such as SHA-256."

## 50-60 sec - Download + CTA

"Download the ZIP, keep the receipt, and send feedback. Retail Alpha is for small packages first."
