# FAQ

## What is Farpy?

Farpy is a render delivery service for small Blender and Octane packages.

## Who is it for today?

Artists who want to test a small scene, preview, splash screen, or short frame range before sending larger work.

## What do I get back?

A ZIP download and a delivery receipt when the package completes.

## Does Farpy promise huge render-farm scale today?

No. This is Retail Alpha. Start small.

## Does Farpy fake progress?

No. If a real job-progress state is not available, Farpy does not invent one.

## Is there a subscription?

No subscription is advertised for this alpha path.

## Can I use the Blender add-on?

Yes, the add-on page provides Farpy Render Delivery install guidance and a ZIP download.
